   - Automated OWASP Top 10 Red-Teaming scanner.
   - Detects leaked cloud secrets (OpenAI, Stripe, Google, JWT), SQL Injection (SQLi), and Cross-Site Scripting (XSS).

   - Live monitoring of Antigravity model quotas.
   - Automatic failover routing away from depleted pools (0%) to active, high-capacity engines (`gemini-3.8-flash-high`).
